## 来源等级

- **A｜官方规则/帮助**：可核对当前功能说明或规定范围；不代表个案结果。
- **B｜用户材料**：通知、聊天、订单、预约确认、截图或应用状态。记录来源和时间；不完整截图不能证明全部状态。
- **C｜操作建议**：保全现状、避免重复操作、先确认再提交等风险控制建议，不是平台承诺。
- **未知**：无法从材料确认的已读、备份、退款、改签、恢复成功或审批结果。

只读取与当前事故相关的 1 份知识条目。不要向公开服务上传私密聊天或含身份信息的凭证。
