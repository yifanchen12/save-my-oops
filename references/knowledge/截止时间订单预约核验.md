# 截止时间、订单与预约核验

## 截止时间已过或将到

先保存官方通知、提交页面、时间戳、付款/预约凭证和已收到的回执。区分“系统截止时间”“时区”“提交时间”“补交/申诉规则”与用户记忆。不要断言宽限期存在，也不要替用户虚构理由或补造证明。

可逆下一步：通过通知/账户中列出的官方渠道询问是否仍可补交、延期或申诉，并说明真实时间线。先提交无关材料或重复付款可能造成额外问题，需核对收件要求与当前状态。

## 订单/退款/预约出错

对照订单号（可遮挡）、商品/服务、金额、付款时间、商户名称、取消状态和平台消息。预约场景还要核对日期、时区、地点/服务方、改约状态与确认号。账单显示“处理中”不一定等于商家已确认，也不等于退款已到账。

推荐顺序：

1. 先在官方 App/网站确认状态，并保存当前页面与凭证。
2. 避免重复下单、重复付款或再次取消；先询问官方客服/服务方是否已有记录。
3. 需要联系时给用户一条简短草稿，附订单/预约标识和明确诉求，不在公开处贴完整凭证。
4. 如涉及扣款、退款或争议期限，立即核对支付机构与商家的现行规则；时限不明时不要等到最后一天。

## 可复用询问模板

```text
你好，我想核对 [订单/预约编号后几位] 的当前状态。
我看到的页面/通知显示：[原文与时间]。
我实际希望确认：[是否成功 / 是否已取消 / 退款进度 / 能否改期或补交]。
请告知当前记录、需要我补充的材料，以及适用的截止时间/后续步骤。谢谢。
```

模板中的事实需由用户替换并核对。平台、机构、地区、支付渠道和合同约定都会影响处理方式；必须依靠用户持有的原文和当前官方规则，不能从通用经验推断结果。
