<h1 align="center">补锅侠 · SaveMyOops</h1>

<p align="center"><strong>事情搞砸时，先稳住局面，再选一个低风险、可撤回的补救动作。</strong></p>
<p align="center">一个处理消息、文件、截止时间、订单与预约事故的 AI 补救技能。可用于支持 Agent Skills 的 AI 助手，也可以把文件作为普通上下文交给其他助手。</p>
<p align="center"><img alt="Validate Skill: passing" src="https://img.shields.io/badge/Validate%20Skill-passing-brightgreen"> <img alt="License: MIT" src="https://img.shields.io/badge/License-MIT-yellow"></p>

如果它帮你在慌乱时少做一次不可逆操作，欢迎点亮 ⭐ Star，也欢迎 Follow 关注后续更新。仓库暂不展示星数。

很多意外会让人立刻想“赶紧做点什么”：再发一条解释、继续点恢复、重复下单，或者错过正式联系渠道。补锅侠先判断事情是否时间敏感、是否难以撤回，再把已发生的事实、推断和未知项分开。它会从当前场景中找一个能保留选择余地的第一步。

它不是代替用户操作的自动修复工具。它不会替你发送消息、删除或恢复文件、付款、取消预约或提交申诉；当软件版本、平台规则或账户状态不清楚时，会先提示核实，而不编造按钮路径和结果承诺。

## 它能帮你解决什么

| 你遇到的问题 | 补锅侠会怎么帮 |
| --- | --- |
| 消息发错人、发错群或说重了 | 判断是否需要及时更正，区分可确认事实和对方反应的未知，起草一条由你检查的消息 |
| 文件误删或被覆盖 | 优先保留当前状态，确认本机/云端/版本历史，再核对官方恢复流程 |
| 错过作业、申请或付款截止 | 找出正式通知、时间戳和联系渠道，帮你准备真实、简短的补交或延期询问 |
| 订单重复、金额异常或退款未到 | 先确认订单与支付状态，提醒避免重复付款或误取消，整理客服需要的信息 |
| 预约日期、地点或服务状态出错 | 对照预约凭证，确认时区、变更记录和官方联系渠道，准备核实请求 |

## 安装

### 支持 Agent Skills 的 AI 助手

如果你的助手能够从 GitHub 或本地目录安装 Agent Skills，把下面这段发给它：

```text
请从 https://github.com/yifanchen12/save-my-oops 安装补锅侠（SaveMyOops）Agent Skill。保留 SKILL.md、references 和 scripts；安装前说明目标 Skill 目录，不要替我发送消息、删除/恢复文件、付款、取消或提交表单。
```

不同助手的 Skill 目录、加载方式和调用语法可能不同。完成安装后，按产品自身说明重新加载技能；有些助手支持 `$save-my-oops`，也可以直接说“使用补锅侠帮我处理……”。

### 没有 Agent Skills 安装功能的 AI 助手

把 `SKILL.md` 和当前事故对应的一份 `references/` 指南一起提供给助手，并说明“先判断时间敏感和不可逆风险，再给我低风险、可撤回的第一步”。脚本只能在有 Python 的本地环境运行；否则按指南分析，不要让助手假装已经执行脚本。

## 第一次使用

```text
发生了什么：文件被覆盖
大约什么时候：今天 14:20
设备/应用/版本：Windows；应用版本还不知道
当前状态：文件仍开着，没有继续保存
我最担心：恢复旧版本会不会覆盖现有内容
请先给：风险级别、现在最安全的一步、暂时别做的动作、需要核实的问题
```

只给解决问题所需的材料。聊天、订单、预约确认或文件路径中的姓名、联系方式、住址、支付信息可先遮挡；密码和验证码不要提供。

## 一个典型回答如何产生

```text
事故描述
  → 判断时间敏感性与不可逆性
  → 分开记录用户提供、可见凭证、推断和未知项
  → 只加载当前事故对应的指南/资料
  → 先给保留现状的可逆动作
  → 需要时起草一条真实、克制、由用户决定是否发送的消息
  → 对版本、账户和平台规则要求现场核实
```

例如，文件还处于打开状态且刚被覆盖：先停止编辑并保留窗口，记录发生时间和文件位置，再确认应用、同步盘与备份后检查当前官方版本历史。不要把恢复保证写成事实，也不要直接把旧版本覆盖到原件。若恢复窗口可能正在流逝但设备/版本未知，仍应先保留凭证并尽快核实；“待确认”不能变成拖延理由。

示例输入输出见 [`examples/`](examples/)。本地风险分流脚本：

```bash
python scripts/triage.py < examples/input.json
```

PowerShell：

```powershell
Get-Content -Raw examples/input.json | python scripts/triage.py
```

## 局限与隐私

- 不访问设备、邮箱、聊天应用或商家账户；不能确认对方已读、文件可恢复、退款到账、补交获批或预约修改成功。
- 不会自动发送、删除、覆盖、恢复、付款、取消、申诉或提交表单。所有有外部影响的操作由用户查看当前页面后决定。
- 软件版本、地区、账户类型和平台政策可能变化。先核实官方说明，不照搬过时的按钮路径或处理时限。
- 随附脚本只按用户输入作风险分类，本地运行、不联网、不保存输入。
- 若涉及人身安全、勒索、账户接管或重大资金损失，优先联系可信的人、平台官方支持或当地专业渠道。
