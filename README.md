# 补锅侠 · SaveMyOops

> **事情搞砸时，先稳住局面，再选一个低风险、可撤回的补救动作。**
>
> 面向支持 Agent Skills 的 AI 助手，也可以把文件作为普通上下文交给其他 AI 助手使用。

补锅侠适用于消息发错、文件误删或覆盖、错过截止时间，以及订单/预约出错。它会先识别时间敏感和不可逆风险，再把已知事实、推断和未知项拆开。它只提供建议和草稿，不会替你发送、删除、恢复、付款、取消或提交。

## 它能帮你处理什么

| 你遇到的情况 | 补锅侠会怎么帮 |
| --- | --- |
| 消息发错人或说重了 | 先判断是否需要尽快澄清，再拟一条真实、克制、由你确认的消息 |
| 文件误删或被覆盖 | 优先保留当前状态和恢复机会，确认设备、软件、同步与备份信息 |
| 错过作业、申请或付款截止 | 找到正式通知与联系渠道，准备简短的补交/延期询问 |
| 订单重复、金额或退款状态异常 | 先核对订单和支付状态，避免重复付款或误取消 |
| 预约日期、地点、服务状态出错 | 对照确认信息，拟定向官方渠道核实的下一步 |

## 安装与使用

### 支持 Agent Skills 的助手

如果你的助手能从 GitHub 或本地目录安装 Agent Skills，可以把公开仓库地址发给它，要求它安装 `save-my-oops`：

```text
请将 https://github.com/yifanchen12/save-my-oops 安装为一个本地 Agent Skill。保留仓库中的 SKILL.md、references、scripts；不要替我发送消息、删除或恢复文件、付款、取消或提交表单。
```

技能目录和安装方式由各助手决定。安装后重新加载/开启该助手的 Skill 功能；有些产品支持 `$save-my-oops`，有些使用名称或自然语言调用，具体以产品说明为准。

### 其他 AI 助手或手动使用

若助手没有 Skill 安装功能，把本仓库的 `SKILL.md` 和当前事故对应的一份 `references/` 指南一起附上，并告诉它“请先判断风险，再只给我低风险、可逆的第一步”。需要时可在本地运行分流脚本；没有 Python 环境也可以只用流程指南，不要让助手假装执行过脚本。

## 第一次使用，可以这样描述

```text
发生了什么：文件被覆盖
大约什么时候：今天 14:20
设备/应用/版本：Windows；应用版本暂时不知道
当前状态：文件还开着，没有继续保存
最担心什么：不要让恢复操作覆盖当前副本
请先判断：是否有时间敏感或不可逆风险？现在最安全的一步是什么？哪些规则要先核实？
```

只提供解决问题所需的信息。消息内容、订单号、预约确认或文件名可先遮挡姓名、联系方式、地址、支付信息等个人字段。

## 一个典型回答会长这样

```text
### 先判断风险
- 风险：中高；文件可能仍处于打开状态，继续保存可能覆盖更多内容。
- 尚未知：应用、版本、云同步与备份状态。

### 现在先做
1. 暂停编辑；保留当前窗口和文件，不要再保存或运行恢复工具。
2. 记下文件位置、发生时间和最近一次正常版本的大致时间。
3. 确认应用和云盘，再按其当前官方说明检查版本历史/回收站。

### 暂时别做
- 不要对原文件执行覆盖式恢复；先确认是否有副本或可预览的旧版本。
```

示例输入输出见 [`examples/`](examples/)。本地风险分流脚本：

```bash
python scripts/triage.py < examples/input.json
```

PowerShell：

```powershell
Get-Content -Raw examples/input.json | python scripts/triage.py
```

它只根据输入给出风险标签和建议，不会访问设备或执行操作。

## 参考资料与知识库

场景操作指南位于 `references/`；[`references/knowledge/`](references/knowledge/README.md) 收录官方文件恢复说明、消息补救原则，以及平台规则核验方法。指南不会把某个版本的界面路径当成永久规则；遇到时限或账户规则，应核对当前官方页面、账户类型和交易凭证。

## 局限与隐私

- 不能确认对方是否已读、文件是否能恢复、退款是否到账或延期是否获批。
- 不登录设备或账户，不自动发消息、删/恢复文件、提交申诉、取消预约、付款或重复下单。
- 具体应用版本、地区、账户类型和平台政策会变化；信息不足时先给通用的可逆动作，并明确要求核实。
- 随附脚本本地运行、不联网、不保存输入。不要粘贴密码、验证码、完整支付信息或未遮挡的私人聊天/文件。

若涉及人身安全、勒索、账户接管或重大资金损失，优先联系可信的人、相关平台官方支持或当地专业渠道。
